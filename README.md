##Mafia Media

THE NIGHT IS YOURS

A Persian-first online multiplayer Mafia game platform.

Features

- User registration and login
- Create and join private game rooms
- Six-digit room codes
- Online multiplayer gameplay
- Dynamic player capacity
- Mafia game scenarios and roles
- Persian and English languages
- RTL and LTR support
- Player profiles and avatars
- Game coins and marketplace
- Admin and management panel
- Real-time game server
- Supabase authentication and PostgreSQL database

Technology

- React
- TypeScript
- Supabase
- PostgreSQL
- Node.js

Project Goal

Build a complete, secure, real-time multiplayer Mafia platform for Android and web.

Created by Pedram.m.AMafia Media
